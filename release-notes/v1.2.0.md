## What's new

### Know when a clip really saved
- After the hotkey, the popup shows **Saving clip** while Laugh Clipper checks Medal's clips folder, then
  **Clip saved · Rocket League** (or whichever game) once the clip is really there.
- If Medal didn't make a clip, for example because the hotkey doesn't match, it says **Clip didn't save**
  instead of pretending.
- Medal's clips folder is found automatically. You can pick a different one on the **Clipping** page, or turn
  the check off there.

### Clip history
- A new **History** page lists every clip: what was heard, where, in which game, the score, and whether it
  saved. Click **Show** to jump to the file in Explorer.

### Tune each sound separately
- Each sound on the **Detection** page now has an arrow that opens its own options:
  - **Its own trigger level**, for sounds like shouting that score differently from laughter.
  - **Which audio it listens to**. For example, listen for shouting only on your mic and voice chat, so
    explosions in the game don't set it off.

### Setup guide
- New installs get a short setup guide: match Medal's hotkey, pick your audio, and laugh for a few seconds to
  set the trigger level automatically.
- Already set up? Try it any time from **General → Run Setup Again**.

### Tray icon shows what it's doing
- Grey when detection is paused, and an orange dot while it's waiting for a game or Medal isn't running.

### Fixes
- With **Only listen while playing** on, the meters on the Audio and Detection pages stayed empty. Laugh
  Clipper now always listens while its own window is in front, so you can test and tune it without a game
  running.

Your settings carry over, and nothing changes how it works until you use the new options.
